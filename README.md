## 🎯 What Is This?

**CantGetCaught-Code** is a stealth web app disguised as **Visual Studio Code** that displays:
- 📈 **Live Stock Market Data** - NIFTY 50, SENSEX with real-time prices, changes & volume
- 📰 **Breaking News** from 7+ sources (NDTV, Economic Times, Hindustan Times, etc.)
- 🏏 **Live Sports Updates** (ESPN Cricinfo)
- 💻 **Tech News** (Gadgets360)

**Perfect for:** Traders monitoring markets, news enthusiasts, sports fans, and professionals staying informed during office hours.

> **Pro Tip:** Press **F11** for fullscreen mode - complete immersion! 🎮

## 🚀 Quick Start

```bash
# Clone the repo
git clone https://github.com/Lokeshsingh78/cantgetcaught-code.git

# Navigate to directory
cd cantgetcaught-code

# Install dependencies
npm install

# Start development server
npm run dev

# Open in browser
# Navigate to http://localhost:3000

# Press F11 for fullscreen mode! 🎯
```

**That's it!** You're now browsing news & tracking stocks like a pro! 😎

## 🎮 Usage Guide

### Essential Tips

1. **Fullscreen Mode** 🎯
   ```
   Press F11 to enter fullscreen
   Complete immersion, zero distractions
   Perfect for multi-monitor setups
   ```

2. **Tab Navigation**
   - `index.js` → News articles
   - `fetch.js` → Stock market data
   - Switch tabs to change between news/stocks

3. **Auto-Refresh**
   - News updates every 60 seconds
   - Stock prices refresh automatically
   - No manual refresh needed!

### Pro Tips 💎

✅ **Use F11 fullscreen** for best experience  
✅ **Multi-monitor**: Real work on screen 1, this on screen 2  
✅ **Each file = different content**: index.js (news), fetch.js (stocks)  
✅ **Perfect timing**: Check during compile time or build processes

## 🏗️ Tech Stack

- **Framework:** Next.js 12 (Server-side rendering)
- **UI Library:** React
- **Styling:** CSS3 (Custom VS Code dark theme)
- **Deployment:** Vercel (Lightning fast)
- **Data:** Real-time fetching with getServerSideProps
